0-hello_world, prints Hello, world followed by a new line to standard output.
1-confused_smiley, displays a confused smiley.
2-hellofile, displays the comtent of /etc/passwd file using the cat command.
3-twofiles, displays the contents of /etc/passwd and /etc/hosts using the cat command.
4-lastlines, displays the last 10 lines of /etc/passwd using the tail command.
5-firstlines, displays the first 10 lines of /etc/passwd using the head command.
6-third_line, displays the third line of the file iacta using head and tail.
7-file, creates a file \*\\'"Best School"\'\\*$\?\*\*\*\*\*:) containing the text Best School.
8-cwd_state, writes the output of ls -la to the file ls_cwd_content, overwriting it or creating it.
9-duplicate_last_line, duplicates the last line of the file iacta by appending it to the end of the file.
10-no_more_js, deletes all regular files (not the directories)  with the .js extension from the current directory and subfolders.
11-directories, counts all directories and subdirectories including hidden ones but excluding the current directory itself.
12-newest_files, displays the 10 newest entries in the current directory one per line and sorted from newest to oldest.
13-unique, reads words from standard input and prints only words that appear exactly once and there sorted.
14-findthatword, displays every line containing the pattern root from the file /etc/passwd.
